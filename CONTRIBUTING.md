# Mitmachen

1. Repo forken und klonen
2. Branch anlegen: `git checkout -b projekt/feature-name`
3. Änderungen in **deinem Projektordner** machen (`projects/<name>/`)
4. Pull Request öffnen, kurz beschreiben was und warum
5. Mindestens eine Review von einer anderen Person

## Gute Einstiegspunkte

- Issues mit Label `good first issue`
- Dokumentation verbessern
- Ein Proposal kommentieren oder testen

## Konventionen

- Jedes Projekt hat eine eigene `README.md` (Ziel, Setup, Status, Lead)
- Commit-Messages kurz und im Imperativ, z. B. `Add login page`
- Keine Secrets committen
