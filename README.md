# 🌱 Crowd Repo

Ein offenes Repo, das die Community gemeinsam baut. Jede:r kann ein Projekt vorschlagen, wir stimmen ab, was als Nächstes gebaut wird, und bauen es zusammen.

## So funktioniert's

1. **Idee vorschlagen** → [Neuen Proposal öffnen](../../issues/new?template=proposal.yml)
2. **Diskutieren & abstimmen** → 👍 auf den Proposal-Issue (Details in [GOVERNANCE.md](GOVERNANCE.md))
3. **Gewinner wird Projekt** → Ordner unter `projects/<name>/`
4. **Zusammen bauen** → Fork, Branch, Pull Request ([CONTRIBUTING.md](CONTRIBUTING.md))

## Prinzipien

- Jede Idee ist willkommen, jede Stimme zählt gleich
- Kleine, fertige Schritte statt große, ewige Pläne
- Mehrere Projekte parallel sind gewünscht
- Respektvoller Umgang ([CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md))
